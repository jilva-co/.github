# Support

## Where to ask

- **Questions / ideas:** [GitHub Discussions](https://github.com/orgs/jilva-co/discussions) — Q&A or Ideas category.
- **Bugs / features:** Issues in the relevant repo (`jilva-rs`, `website`, …) using the templates.
- **Security:** See `SECURITY.md` — do not use Discussions or public issues.

## What to include

Repo + commit hash, OS + terminal + font, minimal reproduction, expected vs actual behavior, logs.

## Response expectations

Jilva is maintained by a small team. Discussions are best-effort; be patient, be precise. Well-written reports get answered first.
