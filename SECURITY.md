# Security Policy

## Supported versions

Jilva has no stable release yet. All `jilva-*` code is pre-alpha and should not be used in production.

| Project | Status |
|---------|--------|
| `jilva-rs` | Design stage — no security support yet |
| All others | Not started |

Once we publish `0.1.0`, this table will list supported minor versions.

## Reporting a vulnerability

**Do not open a public issue for security problems.**

- Use GitHub private vulnerability reporting: `Security` tab → `Report a vulnerability` on the affected repo.
- Or email the org owners (add address when `branding` lands; until then use private reporting).
- Include: affected repo/commit, impact, reproduction steps, and whether exploit is public.

We aim to acknowledge within 72 hours and will keep you updated. We ask for 90 days coordinated disclosure for serious issues.

## Scope

In scope: `jilva-co/*` source, release artifacts, website. Out of scope: third-party forks, social engineering, physical attacks.
